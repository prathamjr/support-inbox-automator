# {{BRAND}} support policies

Claude fills this in with the owner during setup (SKILL.md, step 6), in the owner's own words. The run follows it exactly
and never offers anything it doesn't allow. Lines starting with "Example:" are only there to show the format; setup
replaces them. When the owner changes a policy later, edit this file and add a line to RULES.md.

## The store in one paragraph
Example: We sell home and kitchen products online across India. Most orders are prepaid. Orders ship from two warehouses. Order numbers look like #1234.

## Refunds
Example: The email run never promises, confirms or mentions a refund. Every refund request is an owner draft.

## Cancellations
Example: An order can be cancelled only before it is booked with a courier. Once booked or on its way: "it's already been processed / it's on its way, so I'm not able to cancel it". Never hold or cancel an order from an email.

## Wrong, short or damaged items
Example: Always ask for a photo (video for "doesn't work") and the outer label first. Once a photo arrives, it's an owner draft; the owner decides on a replacement.

## Returns and exchanges
Example: No returns for change of mind. Size exchanges within 7 days of delivery, owner draft.

## Store credit, discounts, gifts, compensation
Example: Never offered by the email run.

## Delivery promises
Example: Never give a delivery date or a time frame. Give the courier, tracking number, last scan and tracking link.

## Product facts the run may use for pre-sale questions
Example: The bottle is 750 ml, stainless steel, dishwasher safe, lid not microwave safe. (Anything not listed here: owner draft.)

## Things that look like a problem but aren't
Example: Free gifts in an offer ship as a separate parcel and can arrive a few days after the main order. Explain that; it is not a missing item.

## Escalations: always the owner
Example: Legal or consumer-court threats, chargebacks, influencer/press, bulk or wholesale enquiries, anything about a person's health getting worse.
